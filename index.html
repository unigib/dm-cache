A 6502 has an 8-bit CPU and a 16-bit address bus. This teaching model adds a unified cache; a real 6502 has no built-in cache. It uses real instruction bytes but does not model actual processor timing, dummy bus cycles, writes, or the full processor. Programs stop at the end of the listing, not with a 6502 halt instruction.

Selecting an example restores the populated cache; either reset reloads its code and data, resets the CPU, and clears history. Other memory bytes equal their address modulo 256.
